# Hacktivity

This repository contains disclosures of cool bugs and vulnerabilities reported by Hacktron.

## About

Welcome to Hacktron Hacktivity - a collection of interesting security findings, bug reports, and vulnerability disclosures discovered and reported by Hacktron. This repository serves as a public archive of disclosed security issues, providing insights into various attack vectors, exploitation techniques, and security research findings.

## Contents

This repository will include:
- Exact vulnerability and the ticket reported by hacktron
- Detailed vulnerability reports
- Proof of concept exploits
- Security research findings
- Bug bounty submissions
- Responsible disclosure documentation

## Disclaimer

All vulnerabilities and bugs documented in this repository have been properly disclosed through responsible disclosure processes. The information provided here is for educational and research purposes only.
